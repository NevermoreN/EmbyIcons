# 08 Rust 主分支整理与旧版归档

日期：2026-11-06（北京时间）。本轮按用户要求移除旧后端，并将旧版单独保留为分支。

## 分支归属

| 分支 | 内容 |
| --- | --- |
| `main` | Rust 业务、Emby 必需的薄 .NET 适配层、兼容配置 DTO、HTML/JavaScript 页面和构建工具 |
| `legacy-csharp` | 重构前完整 C# 版本，固定基线 `000ee767e29b7a39027689b15796d3ea52166463` |

保留正常 Git 历史，不强制推送或重写已有提交。旧分支以重构前源码为准，不保存中途混合状态。

## 删除与保留

- 删除 `Core`、`Caching`、`Services`、`Helpers`、`ImageProcessing`、`Models`、`Tasks`、`Compat` 中的旧 C# 业务及对应 `Tests`。
- 删除参考后端构建模式、SkiaSharp 和托管内存缓存的直接包引用，以及旧配置常量文件。
- 删除依赖旧后端的 RendererComparison、C# 键反射对照模式和已完成使命的一次性 HostEventProbe。
- 删除未使用的旧技术图标及旧示例截图，保留 Rust 实际引用的 16 个图标、字体及页面图片。
- 保留 `Host`、`Interop`、配置 DTO 和 API 路由：这是 Emby 加载 Rust 核心所需的宿主边界。
- 保留 Rust 的旧缓存读取逻辑，继续兼容 `image-state-v2`，不会因源码清理清空缓存或更换原图。

历史架构和计划继续保留；被删除旧源码的文档链接已改为重构前提交的永久链接。当前构建及安装方式以根 README 和 Rust 核心 README 为准。

## 验证与生产边界

本轮执行一次完整 Linux x86_64 构建，检查原生依赖下载、Rust 编译、素材嵌入、内嵌 ZIP、精简 .NET 项目及最终单 DLL 打包。保留的宿主缓存探针只做编译检查；业务未变，不重跑已通过的绘图基准和生产生命周期测试。

实际结果：完整组合构建通过；HostCacheProbe 使用当前生产宿主程序集编译通过，均为零警告、零错误。新构建包保存在本地忽略目录 artifacts/linux-x64/embyicons.dll，SHA-256 为 fa61f66598056be48fb80ce4d580308f9301e7e244d6ae82d70a6f0f83bb8fcf。本轮未重复运行绘图基准或生产端到端测试。

任务专用宿主程序集、临时构建目录及构建服务器在交付时清理；固定依赖缓存、可交付 DLL 和生产回退备份保留。生产环境保持已验证的 Rust 包，不因删除未参与构建的旧源码而重启服务。生产原图、图片缓存、旧分区和独立回退备份不在本轮清理范围内。
