# 05 当前 Emby 使用情况与重构范围裁剪

核查日期：2026-11-05。用户要求先完善计划，不修改运行代码；本次只读访问当前 NAS 的 Emby 4.10.2.0。本文收紧 02—04 的实施范围，01 继续记录完整现有源码架构。

## 1. 证据与判定方式

- 读取运行中的插件配置、`Library/VirtualFolders`、按媒体类型统计的 `Items` 和 `ScheduledTasks`。没有发起图片请求、执行任务、刷新元数据或重启服务。
- 对照宿主配置文件 `plugins/configurations/embyicons.xml`；SHA-256 为 `056045ffaaad6aaa6851b24647d6903d044b077838f79e8d49aa59bc83ebb00a`。运行配置与文件的 Profile 标量设置一致；三个规则列表在两者中均为空。
- 检查相关缓存文件存在性与评分缓存条目数；没有将原配置、密钥、令牌、用户信息或媒体明细复制进仓库。
- “启用”表示配置会允许这项能力，不等于每张图都有相应数据；“未使用”优先由禁用设置、空规则或不在映射范围的媒体类型证明。不能从没有访问记录推断某个管理按钮从未用过。

## 3. 保留的画面功能

两个 Profile 启用的叠加种类完全相同，位置、优先级和边距仍有差异，必须分别还原：

| 叠加 | 现有来源或依赖 | 保留内容 |
| --- | --- | --- |
| 社区评分 | Emby CommunityRating 及当前实现支持的元数据回退 | 现有数值、来源图标选择与缺数据语义 |
| 烂番茄评分 | CriticRating 及现有元数据回退 | 不强制改为 MDBList 获取来源 |
| 爆米花评分 | MDBList | 请求合并、限流、缓存、失败使用旧值、真实变化后台预绘 |
| MyAnimeList 评分 | MDBList | 现有适用对象与缺值处理；开启不代表所有影片都有 MAL 分数 |
| 分级 | OfficialRating 及内置图标映射 | 原有映射、缺失分级与缺图语义 |
| 收藏数 | Emby 用户收藏数据 | 实际收藏变化定向更新；播放进度不引起制图 |

现有左上评分/收藏竖排、左下分级、优先级、尺寸/间距/边距、字体、百分号与偏移均保留。评分背景形状当前为 None，无须实现圆形/方形背景业务。通用绘图原语可以复用，但不为未使用的排列模式增加设置、样本和验收要求。

## 4. 从本次实现与验收中移除

| 移除项 | 依据 | 边界 |
| --- | --- | --- |
| 音频/字幕语言、声道、音视频编码 | 两个 Profile 对应 Alignment 都为 Disabled | 不读取流来计算这些图标，不迁移其映射与聚合 |
| HDR/视频格式、分辨率、帧率、宽高比、来源 | 全部 Disabled | 不实现技术属性图标和吸附规则；原图解码所需尺寸不在此列 |
| 原始语言、剧集完结状态 | 全部 Disabled | 不迁移这些图标规则 |
| 采样率、音频码率、位深 | 全部 Disabled，且没有适用音乐媒体 | 不迁移音乐技术规则 |
| 标签、文件名关键词 | 对应 Alignment 禁用，两个映射列表均为空 | 不迁移关键词解析、标签规则及多版本路径搜集 |
| 视频子项技术交集、音乐并集、合集 Full、特别篇过滤 | 当前启用规则不要求子项技术聚合；Series 为 Lite，A 合集禁用、B 为 Lite | 不实现这些业务；保留当前 Series/合集本体评分、分级与 Profile 语义 |
| 音乐专辑/艺术家/音轨、照片、MusicVideo；Season/Episode 绘图 | 媒体及 Profile 适用性见上表 | 这些项的事件仍可做必要的关系失效，不能变成新的绘图范围 |
| Thumb/Banner、比例归一化 | 当前禁用 | 不迁移这些输出分支 |
| JPEG/Auto 成品编码配置 | 当前明确为 PNG | Rust 正式成品只实现 PNG；原图 JPEG 解码和 Emby HTTP 缩放/转码保留 |
| 自定义图标目录、CustomOnly、外部图标替换监听 | 目录为空，实际内置图标 | 不做外部目录扫描/监控；内置素材修订与模板缓存仍需管理 |
| 上下背景条、安全区、圆/方评分背景 | 条带关闭、SafeZones 空、背景形状 None | 不迁移相应布局功能；透明 PNG 和现有文字渲染保留 |

“移除”只影响本轮重构，不删除运行中功能、媒体原图、索引、旧缓存或原配置字段，也不表示以后不能另行恢复。

后续明确要求：处理范围只做 `Primary` 海报，所有主动制图入口和分页查询都须直接落实这一限制。PNG 必须无损保存绘图结果；任何压缩调优都不能降低尺寸、量化颜色或切换有损格式。Emby 自身对客户端图片的缩放/转码继续由宿主管理，不扩展为插件制作其他图片类型。

读取旧配置/分区时，仍需保留旧字段及原绑定签名的兼容计算，不能因为 Rust 不实现某项图标就从旧签名里直接删字段，导致所有已有图片换键。后续保存配置也不能清掉这些旧字段。

## 5. 不能靠配置证明未使用的功能

预览、Profile 编辑、导入导出、缓存查看和排障等管理操作缺少可靠的使用历史。本轮保留它们作为配置维护和迁移所需能力，不能声称用户从未使用过。与明确移除领域相关的音乐排障、自定义路径扫描和宽高比图标工具不再要求迁移；对应界面入口需在实施阶段一并隐藏/标明不支持，不能留下可点击但无效的按钮。

保留功能所需的管理路由、管理员权限、进度/失败诊断和静态图标资源继续工作；不用为精简范围重写整套前端。未支持设置在界面上应明确体现，不允许重新启用后静默忽略。

## 6. 用户新要求保留并明确行为

1. **入库自动后台制图**：新增媒体进入统一队列；原图或评分尚未就绪时等待后续事件/有限重试，无客户端请求也能完成。
2. **元数据刷新跟随更新**：ItemUpdated 触发后台核验，评分、分级、原图等画面输入变化时重绘。仅更新时间戳、播放进度或不启用的技术字段不改变插件键、不重画；原图与其他增强器的真实变化仍遵循 Emby 规则。
3. **手动计划任务制图并保存**：保留 Key `EmbyIconsPreDrawPosters`，在 Emby 计划任务中可手动运行和配置触发器；提交同一队列。任务等待其目标作业成功/命中/失败后才报告完成，按适用图片统计绘制、复用、等待/跳过和失败，不能“只入队就显示完成”。有效磁盘成品直接复用。
4. **稳定缓存标识**：列表、后台预绘、实际请求与确切宿主路径闭环；重启、缓存淘汰、换语言、无关配置或元数据时间戳不使插件键漂移。成品由 Emby 保存到磁盘缓存，不另建成品库，不覆盖原海报。

元数据刷新不等于每个通知都强行重画；这既保证画面跟随实际内容，也保留避免重复制图的要求。请求时尚未就绪的原图策略及宿主接口限制，仍须通过 P0/P4 实测，不因范围精简而降低验收条件。

人工任务必须有结束边界：固定本次范围与目标版本，缺输入有限等待后单列延期，继续由自动队列恢复；不无限追逐后续事件。可选评分缺失/404/无提供商 ID 不能阻止首张海报生成。旧配置中对当前范围无效的默认开关继续兼容，不因保留这些字段拒绝加载。

## 7. 对工作包的影响

- P0—P4 的缓存归因、ABI、状态兼容、单队列和请求隔离保留，样本收敛为电影/Series/适用合集的 Primary。
- P5 明确元数据刷新自动核验、收藏变更、手动计划任务等待真实成品；不扩展到音乐或单集/季绘制。
- P6 从“全媒体全图标”改为六类叠加、内置素材、当前布局及 PNG；不再迁移技术/音乐聚合业务。旧状态与摘要只做必要兼容，不能借此清空原状态或改变键。
- P7 保留评分、Profile 和必要管理功能；移除域的界面/接口一并处理，不做全路由业务等价承诺。
- P8 功能矩阵按本文验收；另验证未支持配置明确提示、旧字段往返保留、未映射库不画图。
- P9 的匹配包、备份、试点和回退保留。任务编号继续沿用，范围缩减不等于任务已完成，也不提前承诺性能倍数。
