# 全局收藏海报

版本：`5.61.1.7-nevermore.rust.3`。

用户明确要求收藏不受媒体库是否配置的限制。本规则更新 `09-predraw-progress-and-data-gate.md` 中的配置门槛：收藏是例外，其他评分/分级仍遵守原来的库映射和数据门槛。处理范围仍为 Movie、Series 和 Lite BoxSet 的 Primary 海报。

## 实现

- 收藏数统计所有用户的 `IsFavorite`，不再按该用户当前能否看到媒体过滤；共享增强海报不依赖浏览者身份。
- 已配置媒体库保留原来的布局；收藏标记若被禁用，则补上全局收藏样式。
- 未配置媒体库或未启用海报的配置只绘制收藏标记，不因此启用其他评分、分级。沿用第一套已启用收藏标记的配置样式；没有这种配置时，使用内置左上角收藏标记。
- 用户收藏/取消收藏仍走 Emby 的 `UserDataSaved(UpdateUserRating)` 事件，后台重新统计和发布。最后一人取消后，未配置媒体退出增强发布状态，已配置媒体则保留有数据的其他标记。
- 后台核验和手动任务先合并所有用户已收藏的媒体 ID，去重后补齐；未收藏且未配置的媒体仍跳过。
- 队列满时收藏事件也能进入队首，队尾的补齐项交由维护/重新扫描处理，队列仍限制为 4096 项。
- 旧版缓存投影不包含收藏人数。有收藏的数据不再接管旧版成品；已接管的收藏海报也会迁移一次到 Rust 缓存。收藏变动事件会撤下该项目的旧版缓存关联，包含取消到 0 人的情形，避免旧海报掩盖更新。
- 继续使用稳定画面指纹、Emby 增强缓存和无损 PNG。人数恢复到已有画面时可以复用旧成品；不修改原图或 Emby 自带库。
- 旧作业在提交时被较新的事件取代，属于正常重新排队。适配层使用单独的取消异常，不再将其计作绘图失败或额外施加失败退避；真实异常仍会报告。

## 最小验证

只增加一项 Rust 回归用例，覆盖无配置的全局收藏、仅生成收藏数据、满队列事件优先、拒绝旧收藏缓存、两个用户逐步取消以及最后取消后退出增强状态。

生产验证使用未映射媒体和两个用户，临时执行收藏人数 `0 → 1 → 2 → 1 → 0`，检查后台生成、跨用户一致的图片缓存标识、无损 PNG、取消后的原图回退及原图摘要；完成后还原用户收藏状态。实际结果在验收后记录。
