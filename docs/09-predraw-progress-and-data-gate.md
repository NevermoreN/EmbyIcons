## 进度

原先扫描通过 GUID 查询后逐项读取完整媒体，再转换为内部 ID，扫描结束前没有上报进度，界面因此长时间显示 0%。

现在直接查询内部 ID，避免这次多余的完整元数据读取。启动报告 1%，按实际已提交扫描 ID 比例推进至 50%，随后沿用 Rust 批次处理进度。扫描分母只保存轻量 ID。

保留现有 120 秒批次期限和队列容量限制。手动批次到期会保存当前状态，并将尚未完成项记为 `deferred`；任务完成不等于全库已经绘制完毕。历史补齐继续由后台负责。
