## 功能链与缓存契约

`入库/元数据更新/收藏/合集事件 → Rust 有界队列 → 后台完整快照与输入核验 → 评分解析 → 作业冻结 → Emby GetEnhancedImage → Rust 解码/叠加/原尺寸无损 PNG → 宿主结果路径及原图版本核验 → 发布`。

手动 `EmbyIconsPreDrawPosters` 复用队列和写入路径；以实际完成、制图、复用、等待、失败数报告结果。手动等待最多 120 秒，未完成项如实计为 deferred，自动作业可继续执行。绘图失败初次及最多 5 次重试，新的元数据事件或手动任务可重新触发；原图迟到同样有限等待。

普通图片请求仅查询已发布的固定结构快照，不查询评分或媒体库，不绘图、不排后台修复队列。已发布文件丢失时回退原图并关闭就绪状态；独立维护补齐，并发布单项 `_cN` 新键，避免原图回退被客户端长期缓存后沿用旧 URL。

画面指纹包含源内容、实际显示值、有效视觉参数、图标/字体版本；不含 DLL 版本、启动时间和周期时钟。相同画面复用。新增元数据只影响相关媒体项，过期作业不得发布。

## 实际宿主发现与修正

- Emby 4.10.2.0 / .NET 8.0.28，实际 `Emby.Drawing.dll` SHA-256 `6564d3930d0320cc0e5c5f1313742d129728e4689572130b41f8b67c24becb2c`。
- Emby 从字节加载插件，`Assembly.Location` 可为空；使用注入的 `ProgramDataPath` 定位专属目录。
- 容器系统 glibc 2.43 不代表 Emby 进程 ABI；Emby 自带 glibc 2.34。运行依赖使用经 SHA-256 校验的 Ubuntu 22.04 包，仅解包并内嵌，清单见 `native/runtime-linux-x64-dependencies.json`。
- 宿主实际调用无 CancellationToken 的旧增强回调，因此用异步作业上下文携带冻结键、生成号和取消令牌。
- 实际 `GetEnhancedImage` 失败可能返回原图，完成登记必须验证返回目标，不能仅依据回调结束发布。
- 带 Tag 的原图回退在实际宿主组件中有 365 天缓存策略，因此补齐需新恢复 Tag；缩放缓存以实际返回路径区分。
- 旧 PNG 使用不透明标记，宿主文件扩展名为 `.jpg`；先按旧路径探测命中，缺失才切新 `.png`，不把原图复制为假成品。
- 旧非 fallback 分支使用实时评分周期，可能与绑定中的 `RatingVersion=0` 不同；仅迁移探测时重建该旧键，发布后不继续引入周期漂移。
- 迁移探测使用旧评分磁盘快照，避免先取得新评分却把旧成品登记成新评分画面；后续事件及后台核验按实际显示值比较更新。
- 真实 Added 事件并不保证原图已到达。隔离宿主观察到 Updated 早于 Added、两者均无图，随后刷新才有原图。

已查阅 Emby 官方[自动类型发现](https://dev.emby.media/doc/plugins/dev/Automatic-Type-Discovery.html)和[依赖注入](https://dev.emby.media/doc/plugins/dev/Dependency-Injection.html)。官方文档支持入口、增强器和手动任务接线；缓存和运行库差异以上述实际宿主验证为准。

## 单批性能观察

| 样本 | 原尺寸 | C# | Rust |
| --- | --- | --- | --- |
| A Movie | 1400 × 2100 | 1106.5 ms | 659.5 ms |
| A Series | 500 × 798 | 223.4 ms | 129.9 ms |
| B Movie | 1037 × 1468 | 601.3 ms | 395.0 ms |
| 合计 | 三张 | 1931.2 ms | 1184.3 ms |

该批输入为无增强的真实海报 PNG 快照，包含真实绘图、PNG、磁盘及 Rust ABI 成本，耗时减少约 38.7%。这不是整个 Emby 的稳定性能倍数；没有重复跑分、冷盘测试或压测。跨 Skia 版本像素差集中在边缘：变化像素约 0.49%—1.05%，平均 RGBA 通道差 0.006—0.018/255；已目视对照布局。原尺寸无损 PNG 指渲染结果无损编码，不代表新旧绘图库产生逐像素相同图像。
