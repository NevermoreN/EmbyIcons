## 3. 尚需实施阶段确认

- **P0 的首要前置条件**：未就绪或成品缺失时，宿主能否在不绘图、不污染增强/缩放缓存的同时返回原图，并使列表 Tag、后台目标键和就绪状态一致。若公开接口不足，明确最小宿主需求后再决定后续，不能用惰性制图代替目标。
- `GetEnhancedImage` 只是待核查的入口候选；选择后每个作业只走一个入口，没有依据时保留现有 `ProcessImage`。
- Rust Skia 版本/字体的兼容性和端到端收益仍未测；PNG 无损不放宽，压缩调优只在已有分项计时指出瓶颈时考虑。
- B Profile 实际适用的合集实例尚未确认。保留当前合集/Profile 规则，不假定所有 1,858 个合集都需要制图，也不为找样本做全库调查。
- 宿主清缓存后由后台维护发现缺口，存在维护周期和排队延迟；普通浏览不承担触发补画的职责。
